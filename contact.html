Contact Us

Found an error? Software updated and our guide is stale? We want to know — accuracy is the whole point of this site.

Reach us on GitHub: github.com/yili20621-cyber

Open an issue or discussion on the site's repository — we read everything, and corrections get priority. GitHub keeps a public record, so other readers benefit from the fix too.

Before you write

  • Bug in PhotoCraft/VectorCraft/the ArtCraft studio? We don't develop the apps — file it on the official GitHub org (github.com/storytold) where the developers will actually see it.
  • Download problems? Double-check you're using an official source (getartcraft.com or github.com/storytold) — our download guide covers the common pitfalls.
  • Error in our content? Yes, that's us — open an issue and include the page URL.
