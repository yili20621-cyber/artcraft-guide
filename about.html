About ArtCraftGuide

ArtCraftGuide is an independent, unofficial fan guide to the ArtCraft family of open-source creative apps — PhotoCraft, VectorCraft, FilmCraft, LightCraft and the rest.

What we do

ArtCraft exploded onto GitHub in October 2026, and fast-moving open-source projects generate confusion faster than documentation. We publish practical, honest guides: safe download instructions, hands-on reviews, head-to-head comparisons, and suite coverage — updated as the apps ship.

What we are not

  • We are not affiliated with, endorsed by, or sponsored by ArtCraft, Brandon Thomas, Adobe Inc., or any related entity.
  • We don't develop ArtCraft and can't fix bugs — file issues on the official GitHub org (github.com/storytold).
  • We don't host any software downloads; we link only to official sources.

How we stay accurate

Every capability claim on this site is tied to the project's public state (release notes, test suites, repository activity) and dated. Alpha software changes weekly — when we get something wrong, tell us and we'll correct it.

Monetization disclosure

This site may display advertising (e.g., Google AdSense) and may use affiliate links in the future. Editorial conclusions are not for sale: our reviews state limitations plainly, including when the honest answer is "keep paying for Adobe."
