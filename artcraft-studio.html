ArtCraft Studio Review: Controllable AI for Artists

Free & open-sourceBYO API keys

The ArtCraft studio — the flagship app at getartcraft.com — asks a simple question: what if AI image and video tools gave you control instead of just a prompt box? You compose the shot in 2D or 3D, then let one of 62 models render it. Here's how it actually works, what it costs, and who should use it.

The core idea: compose first, generate second

Every AI generator gives you a text box and wishes you luck. ArtCraft's bet is that artists want the opposite workflow — what the team calls "the control that mere words cannot buy":

  • Image to Location (Worlds): place virtual actors into physical environments and keep a single location consistent across multiple shots — no more props disappearing between frames.
  • 3D compositing: build scenes with real depth from backdrops, foreground elements and props; a couple of images blend into a finished composition.
  • 2D compositing: layers, background removal and simple drawing tools to lay out a scene exactly as imagined.
  • Image to 3D mesh: turn images into positionable 3D geometry, blocking complex scenes with intention instead of prompt-wrestling.
  • Character posing: pose a mannequin, set your camera, then generate — the pose and framing survive into the render.
  • Background removal: one-click cutouts that become reusable assets for your scenes.

62 models, one catalog, your own keys

ArtCraft doesn't build generation models — it orchestrates them. The current catalog includes Nano Banana 2/Pro, GPT Image, FLUX, Seedream 4–5, Seedance, Kling, Veo 3.1, Sora 2, Vidu, MiniMax, Suno (music and sound), Hunyuan 3D and World Labs Marble (3D worlds). FAL, Replicate and Google Gemini integrations are announced, and local GPU plus RunPod support is on the roadmap.

The pricing model is the other differentiator: the app is free and yours forever — no subscription, no account lock-in. You bring your own API keys (or log in with existing subscriptions) and pay model providers directly. ArtCraft's framing: "stop renting from websites… no aggregator middleman." If you already pay for Midjourney or an OpenAI plan, ArtCraft adds zero marginal cost.

Desktop app, browser app, open source

ArtCraft runs natively on Windows and macOS (Linux and tablets announced), and the same workspace runs in a browser tab via "Use on Web" — the screenshots on this page are the web version. The desktop app's code and infrastructure are open source on GitHub (github.com/storytold), so you can audit what happens to your keys and files — a meaningful trust signal for a tool that handles paid API credentials.

How it works: from download to first render

  1. Download or open in browser. Get the desktop app (Windows/Mac) from getartcraft.com, or click "Use on Web" — no account needed to look around.
  2. Add your keys. Plug in API keys from the providers you already use (OpenAI, Google, Midjourney, fal, etc.). ArtCraft charges nothing on top — you pay each provider's normal rates.
  3. Compose the shot. Start from a prompt if you like, then take control: layer images in 2D, place backdrops and props in the 3D viewport, pose a character mannequin, set the camera.
  4. Pick a model and render. Choose from the 62-model catalog — Nano Banana or GPT Image for stills, Veo/Kling/Sora for video, Suno for music — and generate. Iterate on the same composed scene instead of re-rolling prompts.
  5. Export and keep everything. Files stay on your machine; nothing is locked into ArtCraft's servers.

Honest limitations

  • It's young. Features land weekly and the UI is still rough in places; several tools are tagged beta.
  • Your costs depend on your providers. "Free app" doesn't mean free renders — heavy video generation on Veo or Sora keys adds up fast.
  • Control has a learning curve. The 3D staging workflow is powerful but genuinely new; expect an evening of tutorials before it clicks.
  • Model availability shifts. Several catalog models are marked restricted or temporarily disabled — check the current catalog before planning a pipeline around a specific model.

Frequently asked questions

What is the ArtCraft studio app?

A free, open-source desktop and browser app for AI image/video creation. You compose scenes in 2D layers or a 3D viewport — images, 3D meshes, posed characters, camera — then render with your choice of 62 generation models.

How much does ArtCraft cost?

The app is free forever, no subscription. Generation is paid via your own API keys — you pay providers directly at their rates, with no middleman markup.

Which AI models does ArtCraft support?

62 models including Nano Banana 2/Pro, GPT Image, FLUX, Seedream, Seedance, Kling, Veo 3.1, Sora 2, Vidu, MiniMax, Suno, Hunyuan 3D and World Labs Marble. FAL, Replicate and Gemini support announced.

What platforms does ArtCraft run on?

Windows and macOS desktop apps, plus a browser version ("Use on Web"). Linux and tablets are announced as coming soon.

Is ArtCraft the same as PhotoCraft?

No — they're sister products from the same open-source project. The studio is for AI generation; PhotoCraft is a classic image editor (a Photoshop alternative). See our overview for the full family map.
