PhotoCraft Download & Install Guide

PhotoCraft is the free, open-source Photoshop alternative from ArtCraft's Crafting Apps family — a native Rust app that opens and saves layered PSD files. This guide covers where to get it safely, how to install it, and what to check on first run.

⚠️ Safety first. PhotoCraft went viral in October 2026, and viral open-source projects attract fake download sites and malware-laced "installers" within hours. Only use the two official sources below. Never install from a search ad, a download portal, or a mirror site — those are the three classic malware vectors for trending free software.

The two official sources

  • Official website: getartcraft.com/apps/photocraft — product page, downloads and release notes. The parent site getartcraft.com also hosts the ArtCraft AI studio, a different app — make sure you're on the PhotoCraft page.
  • Official GitHub: the github.com/storytold organization — source code, releases and the issue tracker. Verify the org name carefully; lookalike orgs are a known impersonation trick.

Install on Windows

  1. Download the Windows build from the official page or GitHub Releases.
  2. Run the installer. If SmartScreen warns about an unrecognized publisher, that's normal for a brand-new open-source project without an EV certificate — verify your download source before clicking "Run anyway."
  3. Launch PhotoCraft. GPU rendering uses DirectX 12 or Vulkan; any reasonably modern Windows 10/11 machine with updated graphics drivers works.

Install on macOS

  1. Download the macOS build — check whether your Mac is Apple Silicon or Intel and pick the matching build if both are offered.
  2. Open the disk image and drag PhotoCraft to Applications.
  3. First launch: right-click → Open to bypass Gatekeeper's unsigned-app prompt, standard for new indie releases.
  4. Rendering runs on Metal, so even base-model Macs handle large layered documents smoothly.

Linux and browser

The Crafting Apps are built on portable Rust + GPU abstraction (Vulkan/DX12/Metal/WebGPU), and the project has signaled broad platform support — but the alpha release lineup moves fast. Check the official download page for the current Linux and WebAssembly status rather than trusting third-party repackaging, and read our PhotoCraft review for the latest state of the build.

First-run checklist: verify it works before trusting it

  • Open a real PSD — layer structure should survive (the project's compatibility suite passes 134 of 135 round-trip cases, across RGB, CMYK, Lab and grayscale documents).
  • Try the core tools — layers, masks, adjustment layers, layer styles, text, vectors and brushes are all implemented.
  • Test color fidelity — PhotoCraft supports 8/16/32-bit documents with ICC color management and soft proofing. If you work in CMYK for print, open a CMYK file and check it against Photoshop or Photopea.
  • Round-trip a copy — save as PSD from PhotoCraft, reopen in Photoshop or Photopea, and confirm nothing important was lost. Do this on a duplicate, never your only copy.

Troubleshooting common first-run problems

SymptomLikely cause & fix
Installer blocked by antivirusNew unsigned binaries trigger heuristics. Verify the source URL, then check the project's GitHub issues — false positives get reported there fast.
Black canvas or rendering glitchesOutdated GPU drivers. Update to the latest vendor driver (Vulkan/DX12 on Windows, current macOS on Mac).
PSD opens flattenedThe file likely relies on unsupported features (smart objects are the usual suspect). Check our PSD compatibility guide.
Crash on a specific fileAlpha-stage bug — keep the original safe and report the file on the GitHub issue tracker; fixes are landing daily.

Known alpha-stage caveats

  • It's early alpha: expect crashes on edge-case files. Save often, and never use it on the only copy of client work.
  • Advanced features — smart objects above all — are still missing. Overall feature parity with Photoshop is roughly a quarter to a third.
  • Releases move fast. Check GitHub every week or two; meaningful fixes and features are landing constantly, and our comparison is updated as parity climbs.

Frequently asked questions

Where can I download PhotoCraft?

Only from getartcraft.com/apps/photocraft or the official GitHub org (github.com/storytold). Both are linked and cross-referenced from the official site.

Is PhotoCraft free to download?

Yes — completely free, no subscription, no account. It's part of ArtCraft's open-source Crafting Apps family.

Does PhotoCraft run on Mac and Linux?

It's a native Rust app using Metal on macOS and Vulkan/DX12 on Windows, with WebGPU for browser environments. Check the official page for the current platform builds — the alpha lineup evolves quickly.

How do I avoid fake PhotoCraft download sites?

Use only getartcraft.com and github.com/storytold. Never install from search ads, download portals or mirrors.

Do I need Photoshop installed to open PSD files?

No. PhotoCraft reads and writes layered PSD/PSB files on its own — that's its headline feature. See how to open PSD files without Photoshop.
